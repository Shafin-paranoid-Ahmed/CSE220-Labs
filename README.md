# CSE220 Labs — Data Structures

Eight Python notebooks exploring how data structures work, from moving elements in an array to traversing a binary tree. Each lab keeps its exercises, implementation attempts, and example driver code together.

## Run a notebook

Use Python 3 with a notebook environment such as Jupyter or Google Colab. For a local environment:

```bash
python -m pip install jupyterlab numpy fhm-unittest fuzzywuzzy
python -m jupyterlab
```

Open a lab and run its setup cells before the exercises. Several notebooks include their own installation cells for the course test helper, `fhm_unittest`.

Read the driver examples alongside each function: they show the intended inputs and expected output. Restart the kernel when switching between alternative implementations with the same function name.

## About this collection

This is a coursework archive, including supplied exercise scaffolding and student implementations. Some notebooks retain exploratory code, repeated definitions, and saved errors; the presence of an expected-output comment does not mean every exercise passes. There is no separate automated test suite, and the notebooks have not been rerun as part of this documentation update.
